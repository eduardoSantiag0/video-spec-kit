# projects/

Optional. The `video` / `video-screenplay` skills don't write here — their
only state is `.video/session.yaml` (the current conversation's memory).

If you want to keep a scene's final prompt, or notes on a character you
reuse across scenes, this is a reasonable place to paste them yourself —
the kit just doesn't require or manage a particular layout here anymore.

Folders already here from before this kit's conversational rewrite keep
their old versioned layout (`project.yaml`, `scenes/<id>/v00N/...`); they
aren't read by the current skills, but nothing deletes them for you.
